# Pinterest Growth Platform - Basit Frontend

Vite ile oluşturulmuş basit ve hızlı frontend.

## Kurulum

```bash
cd frontend-simple
npm install
```

## Çalıştırma

```bash
npm run dev
```

Frontend http://localhost:5173 adresinde çalışacak.

## Backend Bağlantısı

Frontend otomatik olarak http://localhost:8080 adresindeki backend API'sine bağlanır.

## Özellikler

- 🎨 AI İçerik Üretimi
- 💬 CEO Chatbot
- 📈 Trend Analizi
- 👤 Pinterest Profil Yönetimi
